# UI 复刻台（Mock）

纯前端、假数据、零硬件的可交互 UI 样机，用来改 UI / 试功能流程，不影响桌面软件。

## 运行

```bat
cd ui-web
npm install
npm run dev:mock
```

打开：`http://127.0.0.1:5199/mock.html`

构建静态版：

```bat
npm run build:mock
:: 产物在 ui-web/dist-mock/
```

## 四个页面

| 页面 | 内容 |
|---|---|
| 三维扫描 | 设备连接、实时采集、手持扫描、转台扫描、视图工具、标定/测距 |
| 融合工作台 | 会话列表、3D 预览、融合进度/阶段、产物 |
| 设置 | 导出、性能、外观、设备显示、高级 |
| 关于与更新 | 版本、更新中心、5 条更新日志、安装/驱动、反馈、许可 |

## 场景面板

右上角显示器图标打开（仅复刻台）：

- 设备：未检测 / 已检测 / 连接中 / 已连接 / 驱动异常 / 连接失败
- 更新：无更新 / 有新版本 / 下载中 / 已安装 / 失败
- 融合：空闲 / 45% / 完成 / 失败
- 主题：浅色 / 深色

## 约束

- 不接相机、串口、文件系统、Python 后端；
- 所有数据在 `src/mockapp/state.js` 里，刷新即重置；
- 页面组件在 `src/mockapp/pages/`，样式在 `src/mockapp/mock.css`；
- 真实软件仍由 `shell.py + ui-web` 启动，本复刻台不参与生产构建。

## 与真实 UI 的关系

复刻台是独立入口 `mock.html`，正式构建 `npm run build` 只打包 `index.html`，不会把 mock 代码带进软件。
后续确认的 UI 改动，按组件回迁到 `src/pages` / `src/components`；不要在两套代码里各改一遍。
